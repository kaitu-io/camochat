Verify your copy

Applies to Android 1.0.0 and later

A signing fingerprint is the serial number of a digital seal only we can apply. If the APK you have carries the seal below, it came from us and hasn't been altered. Any mirror is just a copy — the signature is what makes it genuine.

Check an APK

Most people: download only from the links below, not from a link someone forwarded you.

Technical users: print the certificate with apksigner from the Android SDK. The SHA-256 digest must match the fingerprint above.

apksigner verify --print-certs chencang-1.0.0.apk

Each GitHub Release also lists the file's SHA-256, so you can compare a mirror's download byte for byte.

The update config

The app reads a public config file (it contains no personal or device information) that lists download mirrors and the latest version. It is signed with the key above, which is built into the app. The app checks the signature every time and discards anything that doesn't verify — you don't need to do anything.
