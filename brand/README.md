# CamoChat brand

| File | Use |
|---|---|
| `camochat-glyph.svg` | The bubble cat on a transparent background (100-unit grid). Source for every icon. |
| `camochat-icon.svg` | 1024×1024 app icon, full bleed (the OS applies the mask). |
| `camochat-wordmark-on-dark.svg` / `-on-light.svg` | Wordmark. The dashed **h** is intentional: hide it and *camochat* reads *camocat*. |
| `camochat-lockup.svg` | Icon + wordmark, horizontal. |

Colours come from the Moyu tokens: jade `#3FAE8C` on night `#101214` (light-background wordmark: ink `#101214`, h in `#1E7A68`).
Wordmark lettering is Bricolage Grotesque ExtraBold (SIL OFL 1.1), converted to outlines.

At sizes where the dashed **h** would close up (below roughly 24 px tall), draw it solid.
